# Python Playground

Thai-first browser Python learning IDE .

Run all user Python locally in browser via Pyodide module worker; never server execution. Monaco desktop syntax highlighting + genuine static Python completion/signature/hover. Two execution modes: normal and slow visualization/replay from real runtime trace. 3D isometric cartoon scene inspired by user-provided Learnara Instagram reel DeUV8jev3JG, with original assets. World lesson API explicit; arbitrary Python gets variables/stack/objects visualization. Standard library mostly supported subject to browser limitations, package manager for compatible packages, truthful compatibility messages. Local persistence/export/import, no code/input/trace upload. Stop/input/trace bounds required. Dedicated no-secret origin, restrictive CSP, cross-origin isolation for SharedArrayBuffer control. Mobile usable fallback editor.

## Numeric explanation UX

Ordinary calculations use a front-facing 2D board with readable literal values. Reserve 3D high-angle scenes for observed character/world actions. Explain observed changes with prominent arrows in gradual stages: prior snapshot → new observed value → named destination. For newly created variables, do not invent a prior value. Keep upcoming source and completed observed updates distinct; do not infer arithmetic provenance from regex or evaluate user expressions outside execution. Playback pause/seek must stop/reset explanation stages and preserve deterministic history. Respect reduced motion and allow manual explanation steps.
