## Verified teaching observations
- Variables: https://www.instagram.com/learnara.technology/reel/DeWxvupPQai/ — x=5 then x=7, print(x), print(y); undefined y leads to a repair y=x+1. Value replacement represented physically, short questions and execution focus. Translate principle into name binding; Python variables are names referencing objects, not literally independent boxes. Do not imply reassignment destroys every referenced prior object.
- For: https://www.instagram.com/learnara.technology/reel/DeUV8jev3JG/ — compare manual counter/while with for i in range(3); slots0,1,2 and ghosted excluded3, repeated print("Hop!") versus unindented print("Done!"). Emphasize excluded stop and indentation.
- While: https://www.instagram.com/learnara.technology/reel/DeSPdjsvD_k/ — begin with repeating an action versus copying print("Hop!"); circular loop and count. Explain need for progress, repeat visit and exit without inventing boolean-result telemetry.
- Classes: https://www.instagram.com/learnara.technology/reel/DdroGSmhRv6/ — reusable mould and distinct slots; visible class Dog / __init__(self,age) / self.age=age. Explain class versus instance and independent state, not arbitrary class/property inspection.

## Application contract
1. Short Thai question → explain source syntax → show actual recorded local values/output → mention one beginner misconception.
2. Source syntax classifications are educational captions, not an interpreter. Never evaluate user source or re-evaluate a while condition for teaching.
3. A line trace is PRE-line. Say 'กำลังจะทำ' and distinguish observed values from upcoming source. Never attribute snapshot changes to the upcoming line.
4. Output/exception explanations use recorded events. Unknown code is explicit, not synthetic explanation pretending complete support.
5. Use existing token palette, source snapshots, phased arrows, reduced-motion and replay controls. New UI has our own design/assets.
6. Keep safe serializer restrictions: no user repr, property or descriptor evaluation. Classes not fully inspected by existing safe serialization are acknowledged.
7. Examples are original Thai programs: reassignment, range/indentation, while progress, separate Counter objects and intentional NameError repair.
